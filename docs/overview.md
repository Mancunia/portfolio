# Project Overview

## What is this?

The Portfolio project is a highly-optimized, personal web presence platform. It serves as both a showcase for professional work (projects and experience) and a platform for long-form writing (blog).

## Core Principles

1.  **Durability**: Use standard web technologies (CSS, SQL, HTML) to ensure the site remains maintainable for years.
2.  **Performance**: Minimal client-side JavaScript, server-side rendering, and efficient data fetching.
3.  **Independence**: Ownership of data via Supabase and a portable schema.
4.  **Simplicity**: A "quiet" interface that prioritizes content over decoration.

## Target Audience

Indie developers, design engineers, and software architects who want a professional, customizable, and high-performance portfolio.
